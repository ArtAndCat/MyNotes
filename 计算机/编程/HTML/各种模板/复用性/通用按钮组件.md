### 📦 第一步：复制组件代码

请在你的项目中创建一个新文件，例如 `src/components/SmartButton.vue`，然后将下面的代码完整复制进去。

```html
<template>
  <button 
    class="smart-btn" 
    :class="[
      `btn-${type}`,       // 动态类名：根据 type 属性添加不同颜色样式 (primary, danger, success)
      `btn-${size}`,       // 动态类名：根据 size 属性添加不同大小样式 (small, large)
      { 'btn-block': block } // 条件类名：如果是 block 模式，则占满整行
    ]"
    :disabled="disabled || loading" 
    @click="handleClick"
  >
    <!-- 加载状态：显示转圈圈图标 -->
    <span v-if="loading" class="loading-icon">⟳</span>
    
    <!-- 按钮内容插槽：支持传入文字或图标 -->
    <slot>默认按钮</slot>
  </button>
</template>

<script setup>
// 1. 定义接收的属性 (Props)
const props = defineProps({
  // 类型：primary(主要), danger(危险/红), success(成功/绿), default(默认/灰)
  type: {
    type: String,
    default: 'primary'
  },
  // 尺寸：small(小), medium(中), large(大)
  size: {
    type: String,
    default: 'medium'
  },
  // 是否禁用
  disabled: {
    type: Boolean,
    default: false
  },
  // 是否处于加载状态 (自动禁用并显示图标)
  loading: {
    type: Boolean,
    default: false
  },
  // 是否占满整行宽度 (自适应布局核心)
  block: {
    type: Boolean,
    default: false
  }
})

// 2. 定义向父组件发射的事件 (Emits)
const emit = defineEmits(['click'])

// 3. 点击事件处理
const handleClick = () => {
  // 如果未禁用且未加载，才触发点击
  if (!props.disabled && !props.loading) {
    emit('click')
  }
}
</script>

<style scoped>
/* --- 基础样式 --- */
.smart-btn {
  display: inline-flex;           /* 让内容和图标水平排列 */
  align-items: center;            /* 垂直居中 */
  justify-content: center;        /* 水平居中 */
  border: none;                   /* 去掉默认边框 */
  border-radius: 4px;             /* 圆角 */
  cursor: pointer;                /* 鼠标悬停变手型 */
  font-weight: 500;               /* 字体加粗 */
  transition: all 0.3s ease;      /* 增加过渡动画，让颜色变化更丝滑 */
  gap: 6px;                       /* 图标和文字的间距 */
  outline: none;                  /* 去掉点击时的默认轮廓 */
}

/* --- 尺寸样式 --- */
.btn-small { padding: 6px 12px; font-size: 12px; }
.btn-medium { padding: 10px 20px; font-size: 14px; }
.btn-large { padding: 14px 28px; font-size: 16px; }

/* --- 颜色样式 (主题) --- */
.btn-primary { background-color: #409eff; color: #fff; }
.btn-primary:hover { background-color: #66b1ff; } /* 悬停变亮 */

.btn-success { background-color: #67c23a; color: #fff; }
.btn-success:hover { background-color: #85ce61; }

.btn-danger { background-color: #f56c6c; color: #fff; }
.btn-danger:hover { background-color: #f78989; }

.btn-default { background-color: #f4f4f5; color: #606266; border: 1px solid #dcdfe6; }
.btn-default:hover { color: #409eff; border-color: #c6e2ff; background-color: #ecf5ff; }

/* --- 状态样式 --- */
.btn-block {
  width: 100%; /* 核心：宽度100%，实现自适应填满父容器 */
}

/* 禁用和加载状态 */
.smart-btn:disabled {
  cursor: not-allowed;
  opacity: 0.6; /* 变半透明 */
}

/* 简单的加载旋转动画 */
.loading-icon {
  animation: spin 1s linear infinite;
}
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
</style>
```

### 🛠️ 第二步：在其他项目中如何使用

复制上面的文件后，你可以在任何页面这样使用它。

#### 1. 引入组件

```html
<script setup>
import SmartButton from '@/components/SmartButton.vue' // 确保路径正确
</script>
```

#### 2. 常见使用场景示例

```html
<template>
  <div style="padding: 20px;">
    
    <!-- 场景 A: 普通按钮 -->
    <SmartButton type="primary" @click="save">保存</SmartButton>
    <SmartButton type="danger" @click="del">删除</SmartButton>

    <!-- 场景 B: 自适应宽度 (放在 flex 或 block 容器中自动撑满) -->
    <div style="margin-top: 20px;">
      <SmartButton type="success" block>占满整行的按钮</SmartButton>
    </div>

    <!-- 场景 C: 加载状态 (点击后模拟提交中) -->
    <SmartButton 
      type="primary" 
      :loading="isLoading" 
      @click="submit"
    >
      {{ isLoading ? '提交中...' : '立即提交' }}
    </SmartButton>

    <!-- 场景 D: 不同尺寸 -->
    <SmartButton size="small">小按钮</SmartButton>
    <SmartButton size="large">大按钮</SmartButton>

  </div>
</template>

<script setup>
import { ref } from 'vue'
import SmartButton from '@/components/SmartButton.vue'

const isLoading = ref(false)

const save = () => console.log('保存了')
const del = () => console.log('删除了')

const submit = () => {
  isLoading.value = true
  setTimeout(() => {
    isLoading.value = false
    alert('提交成功')
  }, 2000)
}
</script>
```

### 💡 核心修改指南（如果不符合你的预期）

如果复制过去后觉得样式不对，可以修改 `<style>` 部分的这几行：

1. **想改颜色？**  
    找到 `.btn-primary`，修改 `background-color` 后面的颜色代码（例如改成 `#1890ff`）。
2. **想改圆角？**  
    找到 `.smart-btn`，修改 `border-radius: 4px`（改成 `0` 就是方角，改成 `20px` 就是很圆的角）。
3. **想让按钮永远居中？**  
    在 `.smart-btn` 里加上 `margin: 0 auto;`，并确保父容器允许它居中。

这个组件遵循了 **DRY (Don't Repeat Yourself)** 原则，你把逻辑封装在里面一次，以后不管在哪里用，只需要改几个字母（属性）就行了。
